# Design Decisions

future sessions honor them instead of re-litigating. Part of the
**Decision / Domain Learning** capture class — every entry is user-approved
(`"Record this as a design decision? (yes/no)"`).

## Entry template

`YYYY-MM-DD-[slug].md` — Context / Decision / Rationale / **Invariant** /
**Coupling / blast radius** / Alternatives rejected.
