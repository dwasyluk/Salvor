# Design Decisions

Dated records of the *why* behind load-bearing choices in this repository, so
future sessions honor them instead of re-litigating. Part of the
**Decision / Domain Learning** capture class — every entry is user-approved
(`"Record this as a design decision? (yes/no)"`).

## Entry template

`YYYY-MM-DD-[slug].md` — artifact ID `DEC:<kebab-slug>` (RULES §10.1) —
structured header (ID / Subject / Claim / Evidence date / Status), then
Context / Decision / Rationale / **Invariant** / **Coupling / blast radius** /
Alternatives rejected.
