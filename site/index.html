PRIMARY PATH

Works with Claude Code, Codex, Gemini, Cursor, and other MCP-capable CLIs.

  1. Install Serena and GitNexus (see README).
  2. Open your LLM CLI in the project.
  3. Paste SETUP_PROMPT.md and answer 4 questions.
  4. Commit the scaffold. Run gitnexus analyze.
  5. You're done — your repo now has a memory.
$ cat SETUP_PROMPT.md
$ # copy the output; paste into your CLI
$ # answer 4 questions
$ # Salvor scaffolds the rest

SMOOTHER PATH · FUTURE

The v1.0.0 release does not ship this plugin. The universal prompt remains the supported path.

  1. Install the official Salvor plugin when v1.1.0 ships.
  2. Run the interactive initializer in Claude Code.
  3. Answer the same four setup questions.
  4. The plugin scaffolds Salvor from the canonical prompt.
  5. Use health and capture commands to maintain it.
$ /salvor:init        # planned interactive setup
$ /salvor:capture     # planned knowledge capture
$ /salvor:health      # planned system check
$ /salvor:status      # planned repo memory
